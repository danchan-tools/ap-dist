# AutoPunch 転記（ブラウザ拡張・F-7）

AutoPunch の勤務表を、報告サイトの作業報告書に流し込む Chrome 拡張。

**入れ方と毎月の使い方は、セットアップ手順書の「10. ブラウザ拡張を入れる」にもあります。**

## 使うとき（毎月）

**操作はすべて、ブラウザ右上の拡張機能ボタンから行う。**

```
  ① AutoPunch の出力画面を開く
     → 右上の拡張ボタン → ［この月を拡張に送る］

  ② 報告サイトの作業報告書を開く
     → 右上の拡張ボタン → ［AutoPunchから反映］

  ③ 目で確かめて ［保存する］ を押す     🔴 これは人が押す
```

🔴 **拡張は保存ボタンを押さない。**値を入れるところまで。

> 🔴 **AutoPunch を直したら、必ずもう一度［送る］。**
> 拡張が持っているのは**［送る］を押した瞬間の写し**なので、
> あとで AutoPunch を直しても、写しは古いまま。
> **既に入っている値は上書きされる**が、**値が空の日は触らない**（消さないため）。

> 📌 **［送る］が押せるのは「出力画面」だけ。**
> 月間一覧では押せない。画面右上の［出力へ］を押してから使う。

> 📌 **画面には何も足さない。**
> はじめは報告サイトの「保存する」の隣にボタンを差し込む作りだったが、
> **サイトが「保存が始まった」と誤解して、読み込み中の表示が消えなくなった。**
> 人のサイトの箱に自分のものを入れない、というのが結論
> （設計書 §10.3）。

## 入れかた（最初の1回だけ・5分）

| # | やること |
|---|---|
| 1 | Chrome で `chrome://extensions` を開く |
| 2 | 右上の **「デベロッパー モード」を ON** にする |
| 3 | **「パッケージ化されていない拡張機能を読み込む」** を押す |
| 4 | **この `extension` フォルダを選ぶ** |

以降はふつうの拡張機能と同じ。**右上のボタンから使う。**

> 📌 **コードを直したら、`chrome://extensions` の再読み込みボタン（⟳）を押す。**
> 🔴 **そのあと、報告サイトのページも `F5` する。**
> ⟳ だけだと、開いたままのページの中にいる拡張は置いていかれ、押しても反応しない。
> 🆕 AutoPunch のページは `F5` しなくてよい（小窓を開くたびに読む形にした。設計書 §13）。

## ファイル

| ファイル | 何をするか |
|---|---|
| `manifest.json` | どのサイトで動くかの宣言。🔴 **報告サイトの場所を書くのはここだけ**（小窓もここを読む）。🆕 **AutoPunch の場所は書かない**（どこに置いた AutoPunch でも動かすため。設計書 §13） |
| `popup.html` / `popup.js` | 右上のボタンを押すと出る小窓。**操作はここだけ** |
| `autopunch.js` | 🆕 小窓を開いたときだけ、AutoPunch のページの中を読む関数。小窓（`popup.html`）が読み込み、ページへ送って動かす。🔴 関数の外の名前を使わない（Chrome は関数を文字に直して送る） |
| `levtech.js` | 報告サイトで、値を流し込み、入ったかを確かめる（画面の作りは知らない） |
| 🆕 `levtech-screens.js` | 🔴 **報告サイトの画面ごとの定義**（9月分までの画面・10月分からの画面）。報告サイトの作りに頼るものは、すべてここ |

テストは `../tests/extension/`（`npm test` で走る）。
📌 このフォルダの中にテストを置かない。Chrome は `_` で始まるフォルダ（`__tests__`）を含む拡張を読み込まない。

## 報告サイトの画面がまた変わったら

```
  ① levtech-screens.js に定義を1つ足す   🔴 古い定義は消さない（古い作業報告書は古い画面のまま開く）
  ② ../tests/extension/ にその画面のテストを足す
  ③ 本物の画面で「入る」「合計が合う」「保存して残る」を確かめる
```

`levtech.js` と `popup.js` は直さなくてよい。
調べ方と手順は設計書 §11.7・§12.9。

## 覚えていること

`chrome.storage.local` に、その月の分だけを持つ。

| 覚えるもの | 年月・日ごとの **開始／終了／休憩／作業内容** |
|---|---|
| 🔴 **覚えないもの** | **単価・見込み金額・契約時間**（そもそも出力画面に出していない） |

|---|---|
